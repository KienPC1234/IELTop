# Images

Two kinds of files live here.

## App logo and icon

`app.ico`, `logo-256.png`, and `logo-64.png` are generated by
`tools/make-icon/make_icon.py` from `IELTop-rounded.png`. Do not edit them by
hand. To change the look, replace `IELTop-rounded.png` and run the script again
from the repository root:

```powershell
conda env create -f tools/make-icon/environment.yml
conda run -n ieltop-icon python tools/make-icon/make_icon.py
```

`app.ico` is wired into the build through `ApplicationIcon` in `IELTop.csproj`
and is also used by Velopack for the installer.

## Writing Task 1 images

Optional chart, graph, table, or diagram images for Writing Task 1.

To attach one, add `"imageFile": "my-chart.png"` to a Writing part in
`Assets/Exams/*.json`. Put the file here, or in
`%LocalAppData%/IELTop/content/Images` for your own papers.

Missing files do not break the test. The task text still shows and the exam
window says which image is missing.

Formats: png, jpg, jpeg, bmp, gif. Keep images small, under 1 MB.
Only use images you have the right to distribute, and note the source in the
paper JSON, the same as any other exam content.
